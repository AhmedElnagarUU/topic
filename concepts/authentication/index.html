Meet the Building Blocks

Before any auth method makes sense, you need to know the three players involved in every login flow.

Session-Based

Like a coat-check ticket — the server keeps your identity and gives you a small ticket number.

  • Client holds: Cookie with session ID
  • Server stores: Your identity in a database
  • Each request: Server looks you up

JWT Token

Like a signed letter — proof of who you are travels with every request.

  • Client holds: The full signed token
  • Server stores: Nothing about you
  • Each request: Server verifies the signature
